# § 16 Module
1 Ein Modul ist eine inhaltlich und zeitlich abgeschlossene Lerneinheit, die sich aus einer oder mehreren Lehrveranstaltungen zusammensetzt und sich über maximal zwei Semester erstrecken kann.
2 Das Absolvieren eines Moduls kann von Voraussetzungen abhängig gemacht werden.
3 Die Zahl der Teilnehmenden eines Moduls kann beschränkt und/ oder auf eine Zielgruppe eingeschränkt werden.
