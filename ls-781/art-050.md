# § 50
Wenn die Entschädigung für verschiedene Rechte, die mit Beziehung auf das gleiche Grundstück abzutreten sind, im Streite liegt oder wenn es sich um eine Entschädigung für verschiedene Grundstücke unter gleichartigen Verhältnissen handelt, so soll die Behandlung solcher Streitfälle so viel als möglich in einem Verfahren stattfinden.
