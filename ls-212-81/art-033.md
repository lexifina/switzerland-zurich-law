# § 33 Kosten
1 Das Verfahren ist kostenlos, soweit dies von andern Gesetzen so vorgeschrieben ist.
2 Einer Partei, die sich mutwillig oder leichtsinnig verhält, kann in kostenlosen Verfahren jedoch eine Gerichtskostenpauschale auferlegt werden.
3 Wenn die Umstände es rechtfertigen, werden in kostenpflichtigen Verfahren keine Kosten auferlegt.
