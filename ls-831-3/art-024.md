# § 24 Gesuch
Die Zusatzleistungen werden nur auf Gesuch hin gewährt. Das Gesuch ist auf einem amtlichen Fragebogen, der wahrheitsgetreu und vollständig auszufüllen ist, einzureichen. Das Gesuch kann vom Ansprecher persönlich, von seinem gesetzlichen Vertreter, von Angehörigen, die dem Berechtigten gegenüber eine rechtliche oder sittliche Unterstützungspflicht erfüllen, sowie nötigenfalls auch von der betreuenden Behörde oder Fürsorgestelle eingereicht werden. Das Gesuch um Ausrichtung von Beihilfe setzt voraus, dass gleichzeitig ein Gesuch um Ergänzungsleistungen gestellt wird.
